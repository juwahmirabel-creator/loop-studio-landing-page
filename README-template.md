## What I Learned

Through building this Loop Studio landing page, I learned several important web development skills:

- **Navbar design and styling**: I resolved issues with adding a background to my navbar and learned how to structure it effectively.  
- **Optimal use of `<div>` elements and classing**: I improved my understanding of how to structure HTML elements efficiently and apply CSS classes logically.  
- **Responsive design**: I learned how to display a website so it looks good on both mobile and desktop devices.  
- **Problem-solving with AI tools**: While the AI tools helped with brainstorming and structuring, I learned to debug and implement solutions myself.  

Overall, this project strengthened my front-end development skills and improved my understanding of building professional, responsive web pages.
